### Remarks
* DGCA does not publish ticket-wise or route-wise average domestic airfare data for public consumption. Traffic data is available but does not contain airfares.
* Duffel and Amadeus APIs are suitable aggregators but require API credentials to authenticate and fetch real-time data.
* No live/official data was ingested to avoid data contamination with synthetic data.
